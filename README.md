# Agent 应用平台（Agent Platform）

面向内部业务的 Agent 应用平台，统一构建、发布、运行与治理；以共享能力支撑企业内部 Agent 中台。

完整代码与当前功能说明见 [最新开发分支 develop/harness-phase5](https://github.com/djyking/agent-ai-platform/tree/develop/harness-phase5)。本分支目前保留项目入口，尚未合入开发分支实现。

底层 Harness 保留为可嵌入 Java 应用的执行内核与 SDK，仓库名、技术模块名、Java 包名与配置前缀保持不变。生产可用性与跨主机恢复等验收边界见开发分支的 [第五阶段实施记录](https://github.com/djyking/agent-ai-platform/blob/develop/harness-phase5/docs/phase5-implementation.md)。
